# Compliance Copilot

Compliance Copilot is a small AI-powered compliance assistant built for the Tevora Associate Developer take-home assignment.

Users can create an account, sign in, start conversations, ask compliance and security questions, and return later to view their conversation history.

## Features

- Email/password authentication
- Persistent user-specific chat history
- Claude-powered AI responses
- PostgreSQL + Prisma
- User ownership checks for conversations
- Markdown-rendered assistant responses
- Responsive chat interface
- Secure server-side API key usage

## Tech Stack

- Next.js 16 App Router
- React 19
- TypeScript
- Tailwind CSS 4
- Prisma 7
- PostgreSQL
- Anthropic Claude API
- bcryptjs
- jose
- react-markdown
- remark-gfm
